# OneSimulation MCP starter

This folder is the public starter for OneSimulation's MCP server. The server itself ships inside the
OneSimulation runtime; nothing of it is in this repository.

- With the runtime installed, the starter launches its `onesimulation-mcp` and passes everything through.
  Set `ONESIMULATION_MCP` to that executable and `ONESIMULATION_WORKSPACE` to your project folder.
- Without it, the starter offers two tools: `search_examples` searches the public example library,
  `setup_onesimulation` explains how to get and connect the runtime.

Registry name: `io.github.JohMey/onesimulation`. [Website](https://onesimulation.onrender.com/) · [Install guide](https://johmey.github.io/OneSimulation-Showcase/quickstart.html)
