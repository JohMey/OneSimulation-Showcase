Solid mechanics · 3D

Bending of a clamped beam

A clamped beam under an end load: the 3D deflection is graded against Euler-Bernoulli beam theory.

Linear elasticityQ2 hexahedraBeam-theory check
Download the notebook (.ipynb)Download the script (.py)

What it computes

OneSimulation assembles the linear-elastic equilibrium with an isotropic Hooke law and solves for displacement and stress on a structured hexahedral mesh.

What it checks

The tip deflection and the deflection line are compared with u_z(L) = -F L^3 / 3EI; within about 0.3 % for the supplied geometry.

What you need to run it. An installed, activated OneSimulation runtime (Python 3.13). As a student or course instructor, you have free access. Everyone else can start with the 7-day free trial. The notebook itself carries no key. These are numerical verifications against references, not experimental validation.
