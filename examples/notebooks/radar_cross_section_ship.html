Radar cross section of a ship

A 150 MHz radar wave meets the side silhouette of a 12 m boat; the bistatic and monostatic radar cross sections are computed for both polarizations.

STEP importscattered-field formulationperfect conductorPMLfar fieldradar cross section

Run locally with OneSimulation. The example downloads are free. Running them requires an activated runtime. Runtime Alpha 0.2.1a7 · CPython 3.13 on macOS (Apple Silicon), Ubuntu 22.04 (x86-64), and Windows x64. Installation and activation · View pilot plans. Scope of the reference checks.

What it computes

OneSimulation cuts the air around the boat silhouette from a STEP plate and solves only the scattered field, with the incident plane wave as background field: on the conducting boat the total tangential field vanishes, behind the absorbing layer the scattered field. The far-field transform of the field on a circle gives the radar cross section. The script that builds the STEP file comes with the notebook.

What it checks

A conducting cylinder (ka = pi) in the same setup follows the Bessel series to 5.0e-3 (TM) and 8.2e-3 (TE) of the peak cross section; for the boat the scattered width from the far field agrees with the extinction width of the optical theorem to 4.3e-4 (TM, 11.03 m) and 2.7e-4 (TE, 8.90 m).

Geometry

The notebook starts at the import of the CAD files radar_cross_section_ship.step, radar_cross_section_ship_cylinder.step: STEP (AP242), readable by any CAD program, with the names of the faces that the boundary conditions use. Put them next to the notebook.

The geometry script

The script radar_cross_section_ship_geometry.py builds the geometry with the CAD objects of OneSimulation and writes the files. Change a dimension there, run it, and run the notebook again.

"""Geometry of the OneSimulation example "Radar cross section of a ship".

Builds, as thin plates with the CAD objects of OneSimulation, the air around the side silhouette of
a 12 m patrol boat (hull, deck house and mast; radar_cross_section_ship.step, the silhouette cut out
as a hole) in a 22 m x 20 m box whose outer 1.5 m hold the absorbing layer, and the same box around
a conducting cylinder of 1 m radius for the validation (radar_cross_section_ship_cylinder.step).
"""

from onesim.cad.d2 import Profile
from onesim.cad.d3 import Box, Cylinder, Prism

width, height, thickness = 22.0, 20.0, 0.2
air = Box(
    length=width, width=height, height=thickness, origin=(-width / 2, -height / 2, 0.0)
)
silhouette = [
    (-6.0, -1.0),
    (4.5, -1.0),
    (6.2, 0.6),
    (6.0, 0.9),
    (2.0, 0.9),
    (2.0, 2.1),
    (0.6, 2.1),
    (0.6, 3.6),
    (0.35, 3.6),
    (0.35, 2.1),
    (-1.8, 2.1),
    (-2.2, 0.9),
    (-6.0, 0.9),
]
ship = Prism(profile=Profile.polygon(silhouette), height=2 * thickness).moved(
    (0.0, 0.0, -thickness / 2)
)
(air - ship).save("radar_cross_section_ship.step")
(
    air - Cylinder(radius=1.0, length=2 * thickness, origin=(0.0, 0.0, -thickness / 2))
).save("radar_cross_section_ship_cylinder.step")

The notebook

The complete notebook, cell by cell. Run it to produce the figures and the comparison printout.

A distant radar illuminates a boat with a plane wave. The boat scatters part of the wave in all directions; the radar cross section \(\sigma\) measures how strongly it does so in a direction, as the area that would intercept and isotropically re-radiate the observed power. In a two-dimensional section (a body long across the section) it is a length:

\[\sigma(\varphi)=\lim_{r\to\infty}2\pi r\frac{|E_s|^2}{|E_0|^2}=\frac4k|F(\varphi)|^2, \qquad E_s\simeq\sqrt{\frac2{\pi kr}}\,e^{\mathrm i(kr-\pi/4)}F(\varphi).\]

The hull, the deck house and the mast are perfect conductors. The model solves the scattered field only: the incident wave \(E_0\) is given analytically as background_field, and on the conductor the total tangential field vanishes, \(E_s=-E_0\) - a PerfectElectricConductor on the inner boundary (the silhouette) carries the total field, the one behind the absorbing layer the scattered field. Both polarizations are solved: \(E_z\) along the boat (TM, Ez) and \(H_z\) along the boat (TE, Hz). far_field transforms the field on a circle around the boat into \(F\).

| boundary | condition | |---|---| | silhouette of the boat (inner boundary) | perfect conductor, total field \(E=0\) tangentially | | outer box behind the 1.5 m absorbing layer | perfect conductor, scattered field |

Reference (C. A. Balanis, Advanced Engineering Electromagnetics, 2nd ed., §11.5 and §11.8; J. A. Stratton, Electromagnetic Theory, §9.20). A conducting cylinder of radius \(a\) scatters the series \(F=\sum_n s_n e^{\mathrm in\varphi}\) with \(s_n=-J_n(ka)/H^{(1)}_n(ka)\) (TM) and \(s_n=-J_n'(ka)/H^{(1)\prime}_n(ka)\) (TE). For any lossless scatterer the optical theorem ties the total scattered power to the forward amplitude:

\[\sigma_s=\frac1{2\pi}\oint\frac4k|F|^2\,\mathrm d\varphi=\sigma_{ext}=-\frac4k\,\mathrm{Re}\,F(\varphi_{\rm forward}).\]
import numpy as np
from onesim.cad.exchange import load
from onesim.materials import VACUUM_PERMEABILITY, VACUUM_PERMITTIVITY
from onesim.materials.electromagnetic import (
    CartesianPML,
    IsotropicElectromagneticMaterial,
)
from onesim.meshing import TriangularMesher
from onesim.numerics import Numerics
from onesim.numerics.fem import FiniteElement, Lagrange
from onesim.numerics.linear import ComplexSparseDirect
from onesim.physics.electromagnetics import (
    FrequencyDomainMaxwell,
    PerfectElectricConductor,
    far_field,
)
from onesim.simulation import Problem, Simulation
from onesim.visualization import plots, theme
from scipy.special import h1vp, hankel1, jv, jvp

theme.set()

frequency = 150e6
light = 1 / np.sqrt(VACUUM_PERMEABILITY * VACUUM_PERMITTIVITY)
wave, omega, admittance = (
    2 * np.pi * frequency / light,
    2 * np.pi * frequency,
    np.sqrt(VACUUM_PERMITTIVITY / VACUUM_PERMEABILITY),
)

Geometry and mesh

load reads the air around the boat and, for the validation, around the cylinder; section cuts them at half thickness. Quadratic triangles of 0.2 m, a tenth of the wavelength, and 5 cm along the conductors.

bodies = {
    name: load(f"radar_cross_section_ship{suffix}.step").section(
        (0, 0, 1), origin=(0, 0, 0.1)
    )
    for name, suffix in (("ship", ""), ("cylinder", "_cylinder"))
}
meshes = {
    name: TriangularMesher(target_size=0.2, local_sizes={"all": 0.05}).generate(body)
    for name, body in bodies.items()
}

fig = plots.figure(1, 2, size=(16, 7))
plots.geometry(
    bodies["ship"],
    selection={"conductor and outer wall": bodies["ship"].boundaries.all},
    labels=False,
    title="Air around the boat (STEP)",
    ax=fig[0],
)
plots.mesh(
    meshes["ship"],
    groups=("all",),
    legend=False,
    title=f"{meshes['ship'].cell_count} quadratic triangles",
    ax=fig[1],
)
plots.show()

Model

The absorbing layer is a CartesianPML whose damping grows quadratically over the outer 1.5 m; the background material is the same layer around air, so that the incident wave passes through it unchanged. The radar sits on the right, its wave arrives at the elevation angle \(\beta\) above the horizon: \(\hat k=(-\cos\beta,-\sin\beta)\).

damping = lambda x, y, z: np.column_stack(
    (
        3 * omega * np.clip((np.abs(x) - 9.5) / 1.5, 0, None) ** 2,
        3 * omega * np.clip((np.abs(y) - 8.5) / 1.5, 0, None) ** 2,
        0 * x,
    )
)
medium = CartesianPML(material=IsotropicElectromagneticMaterial(), damping=damping)
numerics = Numerics(
    spatial=FiniteElement(element=Lagrange(order=2)),
    linear_solver=ComplexSparseDirect(),
)
incident = lambda polarization, direction: lambda x, y, z: (
    np.exp(1j * wave * (direction[0] * x + direction[1] * y))[:, None]
    * (
        np.array([0.0, 0.0, 1.0])
        if polarization == "Ez"
        else np.array([-direction[1], direction[0], 0.0])
    )
)
models = lambda name, polarization, direction: FrequencyDomainMaxwell(
    domain=bodies[name].domain(),
    frequency=frequency,
    material=medium,
    polarization=polarization,
    background_field=incident(polarization, direction),
    background_material=medium,
    phasor_convention="exp(-i*omega*t)",
    amplitude_convention="peak",
)
direction = lambda elevation: (
    -np.cos(np.radians(elevation)),
    -np.sin(np.radians(elevation)),
)
simulate = lambda name, physics: Simulation(
    problem=Problem(
        name=name,
        geometry=bodies[name],
        physics=(physics,),
        boundary_conditions=(
            PerfectElectricConductor(
                physics=physics, boundary=bodies[name].boundaries.all
            ),
        ),
    ),
    mesh=meshes[name],
    numerics=numerics,
).solve_stationary()
circles = {
    "ship": {"radius": 6.8, "center": (0.0, 1.0)},
    "cylinder": {"radius": 3.0, "center": (0.0, 0.0)},
}

angles = np.radians(np.arange(0.0, 360.0, 1.0))
lit = {"ship": 10.0, "cylinder": 180.0}
cases = {
    (name, polarization): models(name, polarization, direction(lit[name]))
    for name in ("ship", "cylinder")
    for polarization in ("Ez", "Hz")
}
results = {key: simulate(key[0], physics) for key, physics in cases.items()}
bistatic = {
    key: far_field(results[key], physics, angles, **circles[key[0]])
    / (1.0 if key[1] == "Ez" else admittance)
    for key, physics in cases.items()
}

Results

The cylinder, lit from the left (\(\hat k=+x\)), against the Bessel series; then the optical theorem for both bodies: the scattered width from the integral of \(|F|^2\) over all directions against the extinction width from the forward amplitude.

orders, ka = np.arange(-30, 31), wave * 1.0
series = {
    "Ez": -jv(orders, ka) / hankel1(orders, ka),
    "Hz": -jvp(orders, ka) / h1vp(orders, ka),
}
print(
    "cylinder ka = pi      max |sigma - sigma_series| / max sigma    sigma back [m]: computed  series"
)
for polarization in ("Ez", "Hz"):
    exact = (
        4
        / wave
        * np.abs(np.exp(1j * np.outer(angles, orders)) @ series[polarization]) ** 2
    )
    computed = 4 / wave * np.abs(bistatic[("cylinder", polarization)]) ** 2
    print(
        f"{'TM (E_z)' if polarization == 'Ez' else 'TE (H_z)':20s}   {np.max(np.abs(computed - exact)) / exact.max():30.1e}"
        f"                    {computed[180]:8.3f}  {exact[180]:8.3f}"
    )
print(
    "\nbody      polarization   scattered width [m]   extinction width [m]   difference"
)
for (name, polarization), pattern in bistatic.items():
    forward = int(
        np.argmin(
            np.abs(
                np.angle(
                    np.exp(1j * (angles - np.radians(190.0 if name == "ship" else 0.0)))
                )
            )
        )
    )
    scattered = 4 / wave * np.mean(np.abs(pattern) ** 2)
    extinction = -4 / wave * pattern[forward].real
    print(
        f"{name:9s} {'TM (E_z)' if polarization == 'Ez' else 'TE (H_z)':12s}   {scattered:19.3f}   {extinction:20.3f}   {abs(scattered / extinction - 1):10.1e}"
    )

The monostatic cross section is what the radar itself receives: the boat is lit at elevations from 0 to 60 degrees and the backscattered amplitude is read in the direction of the radar.

elevations = np.arange(0.0, 61.0, 5.0)
monostatic = {
    polarization: np.array(
        [
            4
            / wave
            * abs(
                far_field(
                    simulate("ship", physics),
                    physics,
                    np.radians([b]),
                    **circles["ship"],
                )[0]
                / (1.0 if polarization == "Ez" else admittance)
            )
            ** 2
            for b, physics in (
                (b, models("ship", polarization, direction(b))) for b in elevations
            )
        ]
    )
    for polarization in ("Ez", "Hz")
}
print("\nelevation [deg]   monostatic sigma TM [m]   TE [m]")
for b, tm, te in zip(elevations, monostatic["Ez"], monostatic["Hz"]):
    print(f"{b:10.0f}        {tm:12.2f}          {te:8.2f}")

Going further

Change the silhouette in radar_cross_section_ship_geometry.py: tilting the flat walls of the deck house away from the radar removes their specular flashes from the monostatic cross section - the idea of stealth shaping. A lossy coating on the hull is a thin region with a complex permittivity.
