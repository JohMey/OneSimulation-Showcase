Mooney-Rivlin fit to Treloar's rubber

The two-parameter Mooney-Rivlin model is fitted to Treloar's classical tests on natural rubber in uniaxial tension, equibiaxial tension and pure shear.

Material point testMooney-RivlinLevenberg-MarquardtThree load modes

Run locally with OneSimulation. The example downloads are free. Running them requires an activated runtime. Runtime Alpha 0.2.1a7 · CPython 3.13 on macOS (Apple Silicon), Ubuntu 22.04 (x86-64), and Windows x64. Installation and activation · View pilot plans. Scope of the reference checks.

Download the notebook (.ipynb)Download the script (.py)

What it computes

OneSimulation runs the three homogeneous material tests of the incompressible material for every trial parameter pair and fits all 52 measured points with the Levenberg-Marquardt method on their relative deviations; the covariance of the fit gives standard errors.

What it checks

The fit gives c1 = 181.7 ± 7.3 kPa and c2 = 3.5 ± 1.7 kPa after 21 evaluations, equal to the closed-form linear least-squares solution to 1e-5; the relative RMS misfit of the model is 28.7 % in uniaxial tension, 16.6 % in equibiaxial tension and 19.9 % in pure shear, the known limit of the two-term model at large stretch.

The notebook

The complete notebook, cell by cell. Run it to produce the figures and the comparison printout.

Rubber is nearly incompressible and stays elastic up to stretches of 5 to 7. Its behaviour is described by a strain energy density of the isochoric invariants \(\bar I_1,\bar I_2\); the Mooney-Rivlin model is the polynomial of first order,

\[W=c_1(\bar I_1-3)+c_2(\bar I_2-3).\]

For the incompressible material the nominal stress (force per original area) in the stretched direction of the three classical tests is

\[P_\mathrm{uni}=2\Big(\lambda-\frac1{\lambda^2}\Big)\Big(c_1+\frac{c_2}{\lambda}\Big),\quad P_\mathrm{bi}=2\Big(\lambda-\frac1{\lambda^5}\Big)\big(c_1+\lambda^2c_2\big),\quad P_\mathrm{shear}=2\Big(\lambda-\frac1{\lambda^3}\Big)\big(c_1+c_2\big).\]

Data. L.R.G. Treloar, Stress-strain data for vulcanised rubber under various types of deformation, Trans. Faraday Soc. 40, 1944, 59-70: 23 points in uniaxial tension, 16 in equibiaxial tension and 13 in pure shear, from a widely used digitisation of the original figures (nominal stress converted from kgf/cm² to Pa). All 52 points enter the fit with their relative deviation, so that small and large stresses count alike.

Reference. The model is linear in \(c_1,c_2\), so the best fit also follows from a direct linear least-squares solution of the formulas above: the fit through the material tests must arrive there.

import numpy as np
from onesim.materials.solids import (

The material tests

HomogeneousFiniteStrainTest is a single material point under the homogeneous stretch of the chosen mode, with zero traction on the free directions and the incompressibility constraint; a damped Newton method finds the free stretch and the pressure at every point of the curve.

newton = DampedNewton(
    linear_solver=SparseDirect(),
    relative_tolerance=0.0,
    absolute_tolerance=2e-12,
    maximum_iterations=80,
).bind()
tests = lambda c1, c2: {
    mode: HomogeneousFiniteStrainTest(
        material=IsochoricInvariantPolynomial.mooney_rivlin(c1, c2),
        volume_law=IncompressibleVolumeLaw(),
    ).solve(
        mode=mode,
        stretches=stretch,
        solver=newton,
        linearize=centered_array_jacobian,
        stress_scale=1e6,
    )
    for mode, (stretch, _) in treloar.items()
}

The fit

The study service evaluates the three tests for every trial pair and minimises the relative residuals with the Levenberg-Marquardt method. The standard errors come from the covariance of the linearised problem, with the noise level estimated from the residuals.

study = SimulationStudyService(
    (StudyParameter("c1", 1e3, 1e6), StudyParameter("c2", 0.0, 3e5)),
    build=lambda values: tests(values["c1"], values["c2"]),
    solve=lambda results: results,
    measure=lambda results: {
        f"{mode}_{k}": float(value)
        for mode, result in results.items()
        for k, value in enumerate(result.nominal_stress[:, 0, 0])
    },
)
fit = study.fit(
    residuals=lambda values: np.concatenate(
        [
            np.array([values[f"{mode}_{k}"] for k in range(len(stress))]) / stress - 1
            for mode, (_, stress) in treloar.items()
        ]
    ),
    start={"c1": 1.7e5, "c2": 2e4},
    method="levenberg_marquardt",
    maximum_runs=400,
)

Comparison with the reference

The fitted moduli against the direct linear least-squares solution of the same relative problem, and the misfit of the fitted model in each load mode.

shapes = {
    "uniaxial": lambda l: 2
    * (l - l**-2)[:, None]
    * np.column_stack((np.ones_like(l), 1 / l)),
    "equibiaxial": lambda l: 2
    * (l - l**-5)[:, None]
    * np.column_stack((np.ones_like(l), l**2)),
    "pure_shear": lambda l: 2
    * (l - l**-3)[:, None]
    * np.column_stack((np.ones_like(l), np.ones_like(l))),
}
direct = np.linalg.lstsq(
    np.vstack(
        [
            shapes[mode](stretch) / stress[:, None]
            for mode, (stretch, stress) in treloar.items()
        ]
    ),
    np.ones(52),
    rcond=None,
)[0]
best = tests(fit.parameters["c1"], fit.parameters["c2"])
print(f"{'':30s} {'c1 [kPa]':>10s} {'c2 [kPa]':>10s}")
print(
    f"{'fit of the material tests':30s} {fit.parameters['c1'] / 1e3:10.3f} {fit.parameters['c2'] / 1e3:10.3f}"
)
print(
    f"{'standard error':30s} {fit.standard_errors['c1'] / 1e3:10.3f} {fit.standard_errors['c2'] / 1e3:10.3f}"
)
print(
    f"{'direct linear least squares':30s} {direct[0] / 1e3:10.3f} {direct[1] / 1e3:10.3f}"
)
print(
    f"largest relative difference to the direct solution: {np.max(np.abs(np.array([fit.parameters['c1'], fit.parameters['c2']]) / direct - 1)):.1e}; "
    f"converged: {fit.converged}, {fit.run_count} parameter evaluations"
)
print(
    f"initial shear modulus μ0 = 2(c1 + c2) = {2 * (fit.parameters['c1'] + fit.parameters['c2']) / 1e3:.1f} kPa"
)
for mode, (stretch, stress) in treloar.items():
    deviation = best[mode].nominal_stress[:, 0, 0] / stress - 1
    print(
        f"{mode:12s} relative RMS deviation {100 * np.sqrt(np.mean(deviation**2)):5.1f} %, largest {100 * np.abs(deviation).max():5.1f} %"
        f" (at λ = {stretch[np.abs(deviation).argmax()]:.2f})"
    )

The three tests with the fitted model, evaluated on fine stretch grids, and the relative deviation of the model from every measured point.

curves = {

Going further

The two-term model misses the stiffening at large stretch in uniaxial tension and overshoots in equibiaxial tension: fit the Ogden model to the same data (the Ogden example), or a higher-order polynomial IsochoricInvariantPolynomial(((i, j, c_ij), ...)).
