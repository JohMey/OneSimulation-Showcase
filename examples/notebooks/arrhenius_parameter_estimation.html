Arrhenius parameter estimation

Rate constant and activation energy of a first-order decomposition estimated from five isothermal batch experiments at once.

Least-squares fitSimulation studySynthetic data

Run locally with OneSimulation. The example downloads are free. Running them requires an activated runtime. Runtime Alpha 0.2.1a7 · CPython 3.13 on macOS (Apple Silicon), Ubuntu 22.04 (x86-64), and Windows x64. Installation and activation · View pilot plans. Scope of the reference checks.

Download the notebook (.ipynb)Download the script (.py)

What it computes

OneSimulation runs the five batch experiments as homogeneous reaction networks inside a SimulationStudyService; its Levenberg-Marquardt least-squares fit adjusts k_ref and E_a, with every residual evaluation a set of real kinetic runs, and returns their covariance. The data are synthetic: generated from known parameters with 0.5 % noise.

What it checks

From k_ref = 3e-4 1/s and E_a = 80 kJ/mol, 24 study runs give k_ref = 0.993 +/- 0.003 1/ks and E_a = 114.0 +/- 0.4 kJ/mol (true 1.000 and 115); chi^2 = 52 for 58 degrees of freedom; the true pair lies inside the joint 99 % confidence region.

The notebook

The complete notebook, cell by cell. Run it to produce the figures and the comparison printout.

The thermal decomposition of benzenediazonium chloride in water,

\[\mathrm{C_6H_5N_2Cl}+\mathrm{H_2O}\;\longrightarrow\;\mathrm{C_6H_5OH}+\mathrm{N_2}+\mathrm{HCl},\]

is a classical first-order reaction: the nitrogen it releases makes the conversion easy to follow. In a batch experiment at the temperature \(T\) the diazonium concentration decays as

\[\frac{dc}{dt}=-k(T)\,c,\qquad k(T)=k_\mathrm{ref}\exp\!\Big[-\frac{E_a}{R}\Big(\frac1T-\frac1{T_\mathrm{ref}}\Big)\Big].\]

Writing the Arrhenius law around a reference temperature \(T_\mathrm{ref}\) in the middle of the experiments decouples the two parameters \(k_\mathrm{ref}\) and \(E_a\), which makes the estimation well conditioned.

OneSimulation solves each experiment as a homogeneous reaction network (ReactionKinetics, classical Runge-Kutta). The SimulationStudyService wraps the five simulations into one study, and its fit turns them into a least-squares problem: for a trial pair \((k_\mathrm{ref},E_a)\) it runs all five experiments, forms the residuals \(\big(c_\mathrm{sim}(t_j)-c_\mathrm{data}(t_j)\big)/s\) and minimises their sum of squares \(\chi^2\) with the Levenberg-Marquardt method. It returns the estimates with their linearised covariance in physical units.

Reference. The data are synthetic: they are generated by OneSimulation itself from chosen "true" values, \(k_\mathrm{ref}=1.0\times10^{-3}\) 1/s at 50 °C and \(E_a=115\) kJ/mol, of the order reported for this reaction, with normally distributed noise of standard deviation \(s=0.05\) mol/m³ (0.5 % of the initial 10 mol/m³). A correct estimation must recover the true values within the uncertainty that this noise allows and leave residuals of the size of the noise, \(\chi^2\approx N-2\) (Y. Bard, Nonlinear Parameter Estimation, Academic Press 1974; on the reaction: E. A. Moelwyn-Hughes, The Kinetics of Reactions in Solution, Oxford 1947).

import numpy as np
from onesim.cad.geometry import LumpedDomain
from onesim.meshing import LumpedMesh
from onesim.numerics import Numerics
from onesim.numerics.discretization import LumpedParameters
from onesim.numerics.time import ClassicalRungeKutta4
from onesim.physics.chemistry import (
    ReactionIR,
    ReactionKinetics,
    ReactionNetworkIR,
    SpeciesIR,
)
from onesim.simulation import Problem, Simulation
from onesim.simulation.initial_conditions import InitialValue
from onesim.simulation.studies import SimulationStudyService, StudyParameter
from onesim.visualization import plots, theme

theme.set()

Experiments and model

Five isothermal experiments from 40 °C to 60 °C, one hour each, with twelve samples every five minutes. experiments(values) builds the five reaction models for one parameter pair, run(models) integrates them and samples the diazonium concentration.

gas, reference_temperature, initial, noise = 8.314462618, 323.15, 10.0, 0.05
temperatures = (313.15, 318.15, 323.15, 328.15, 333.15)
samples = np.linspace(300.0, 3600.0, 12)
cell = LumpedDomain()
experiments = lambda values: {
    T: ReactionKinetics(
        domain=cell.system,
        temperature=T,
        network=ReactionNetworkIR(
            "diazonium_decomposition",
            "1",
            species=(
                SpeciesIR("diazonium", 0, 1e-27, composition={"H": 1}),
                SpeciesIR("products", 0, 1e-27, composition={"H": 1}),
            ),
            reactions=(
                ReactionIR(
                    "decomposition",
                    {"diazonium": 1},
                    {"products": 1},
                    {
                        "kind": "arrhenius",
                        "activation_energy": 1e3 * values["activation_energy"],
                        "boltzmann_constant": gas,
                        "pre_exponential": values["k_ref"]
                        * np.exp(
                            1e3
                            * values["activation_energy"]
                            / (gas * reference_temperature)
                        ),
                    },
                ),
            ),
            strict_balance=True,
        ),
    )
    for T in temperatures
}
run = lambda models: {
    T: np.interp(
        samples,
        *Simulation(
            problem=Problem(
                name=f"Batch decomposition at {T - 273.15:.0f} °C",
                geometry=cell,
                physics=(model,),
                initial_conditions=(
                    InitialValue(model.concentration("diazonium"), initial),
                    InitialValue(model.concentration("products"), 0.0),
                ),
            ),
            mesh=LumpedMesh(cell),
            numerics=Numerics(
                spatial=LumpedParameters(), time_integrator=ClassicalRungeKutta4()
            ),
        )
        .run(start_time=0.0, end_time=3600.0, time_step=20.0)
        .field(model.concentration("diazonium"))
        .time_series(),
    )
    for T, model in models.items()
}
study = SimulationStudyService(
    (
        StudyParameter("k_ref", 1e-4, 1e-2),
        StudyParameter("activation_energy", 60.0, 180.0),
    ),
    experiments,
    lambda computed: {
        f"{T}_{j}": c for T in temperatures for j, c in enumerate(computed[T])
    },
    solve=run,
)

Synthetic measurements

The true parameters are run once and normally distributed noise is added (fixed seed, so the notebook is reproducible).

true = {"k_ref": 1.0e-3, "activation_energy": 115.0}
clean = study.sweep(combinations=[true]).runs[0].measurements
rng = np.random.default_rng(2026)
data = {key: value + rng.normal(0.0, noise) for key, value in clean.items()}
print(
    f"{len(temperatures)} experiments x {samples.size} samples = {len(data)} data points, noise s = {noise} mol/m³"
)

Least-squares fit

Bounds: \(k_\mathrm{ref}\) between \(10^{-4}\) and \(10^{-2}\) 1/s, \(E_a\) between 60 and 180 kJ/mol. Levenberg-Marquardt starts far from the truth, at \(k_\mathrm{ref}=3\times10^{-4}\) 1/s and \(E_a=80\) kJ/mol.

fit = study.fit(
    residuals=lambda m: np.array([(m[key] - data[key]) / noise for key in data]),
    start={"k_ref": 3e-4, "activation_energy": 80.0},
    method="levenberg_marquardt",
    maximum_runs=100,
)

Comparison with the true values

Standard errors from the linearised covariance, scaled with the residual variance.

print(
    f"{fit.run_count} study runs ({len(temperatures) * fit.run_count} kinetic simulations), converged: {fit.converged}, rank {fit.rank}, "
    f"χ² = {fit.residuals @ fit.residuals:.1f} for {fit.degrees_of_freedom} degrees of freedom"
)
print("parameter            estimate ± standard error        true        deviation")
for name, unit, scale in (("k_ref", "1/ks", 1e3), ("activation_energy", "kJ/mol", 1.0)):
    print(
        f"{name:18s} {scale * fit.parameters[name]:10.4f} ± {scale * fit.standard_errors[name]:.4f} {unit:6s} {scale * true[name]:9.3f}   "
        f"{(fit.parameters[name] - true[name]) / fit.standard_errors[name]:+6.2f} σ"
    )
print(
    f"correlation of the two estimates {fit.covariance[0, 1] / np.sqrt(fit.covariance[0, 0] * fit.covariance[1, 1]):+.2f}; "
    f"rms residual {noise * np.sqrt(np.mean(fit.residuals ** 2)):.4f} mol/m³ (noise {noise})"
)
print(
    f"χ² at the true values exceeds the minimum by Δχ² = {sum(((clean[k] - data[k]) / noise) ** 2 for k in data) - fit.residuals @ fit.residuals:.1f} "
    f"(joint regions of two parameters: 68 % Δχ² < 2.30, 95 % < 5.99, 99 % < 9.21)"
)

The estimates scatter around the truth by their standard errors. For this noise realisation the true pair lies just outside the joint 95 % confidence region and inside the 99 % region, as happens for about one data set in fifty; another seed gives another, equally valid data set and estimate.

Figure

The five experiments with the fitted model; every parameter pair the fit ran (including the finite-difference probes); and the Arrhenius plot.

fitted = study.sweep(combinations=[dict(fit.parameters)]).runs[0].measurements
path = np.array(
    [
        [r.parameters["activation_energy"], r.parameters["k_ref"]]
        for r in fit.runs
        if dict(r.parameters) != true
    ]
)
inverse = np.linspace(1 / 335.0, 1 / 311.0, 50)
fig = plots.figure(1, 3, size=(17, 5))
plots.line(

        f"{T - 273.15:.0f} °C": (
            samples / 60,
            np.array([fitted[f"{T}_{j}"] for j in range(samples.size)]),
        )
        for T in temperatures

    xlabel="time [min]",
    ylabel="diazonium concentration [mol/m³]",
    title="Data and fitted model (dashed)",
    legend="upper right",

)
plots.line(

    scale="logy",
    xlabel="activation energy E_a [kJ/mol]",

    title="Path of the fit",
    legend="lower right",

)
plots.line(

        "fitted model": (
            1e3 / np.array(temperatures),

Going further

Halve the noise and the standard deviations halve; drop the 40 °C and 60 °C experiments and watch \(E_a\) become much less certain while \(k_\mathrm{ref}\) hardly changes, the reason for spreading experiments over a wide temperature range. Real data, for example nitrogen volumes read from a gas burette, replace the synthetic data dictionary directly; the measured volume is proportional to the converted amount \(c_0-c(t)\).
