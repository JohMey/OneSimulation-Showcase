runtime function

runtime(*, linear=None, projection_kernel='auto', projection_parallel=False, execution_profile=None, linear_solver=None, numerical_registry=None)

Configure nodal projection's solver and independent sparse RHS execution.

projection_kernel selects auto/NumPy/Numba; auto uses Numba when installed. Explicit parallel execution requires Numba and is never silently ignored. These options do not override the linear solver node.

simplex_nodal_interpolation function

simplex_nodal_interpolation(name: str, source_mesh: object, target_mesh: object, *, unit: str = '1', provider_id: str | None = None) -> TransferOperator

Declare nonconservative 2D/3D nodal simplex interpolation.

The source needs ordered triangle/Tet4 connectivity and the target needs point coordinates. Every target point must be covered by a source simplex.

solved_field function

solved_field(result: object, field_id: str, *, unit: str, value_kind: str | None = None, value_type: str | None = None, component_count: int | None = None, input_id: str | None = None, target_system_id: str | None = None, target_field_id: str | None = None, transfer: str | None = None, provider_id: str | None = None, coverage_policy: str = 'centroids', extrapolation: str = 'reject', conservation_tolerance: float = 1e-10) -> SolvedSpatialFieldInput

Declare a qualified result field for later use on a Study target mesh.

The declaration retains source-result and mesh fingerprints but performs no mapping until input.resolve(target_carrier) is called. All methodology adapters can use the same field handoff contract. Point fields require the identical carrier; cross-mesh remaps currently require Tet4 cell support. 1D point fields accept explicit linear interpolation; 2D/3D nodal simplex fields accept explicit barycentric interpolation. Interpolation rejects uncovered target coordinates unless extrapolation='clamp' is explicitly requested. target_system_id binds the input to a named Study subsystem; an optional target_field_id names the receiving callback input, while input_id disambiguates multiple declared sources.

tetrahedral_cell_projection function

tetrahedral_cell_projection(name: str, source_mesh: object, target_mesh: object, *, unit: str = '1', provider_id: str | None = None, coverage_policy: str = 'centroids') -> TransferOperator

Declare a Tet4 cell-field projection with no outside extrapolation.

Accepts neutral mesh carriers or result mesh_support mappings. This centroid-sampling method is explicitly non-conservative; set coverage_policy='vertices_and_centroids' for strict node coverage. Use a separate volume-overlap remap when an integral conservation guarantee is required.

Declare exact Tet4 overlap remap, requiring equal polyhedral domains.
