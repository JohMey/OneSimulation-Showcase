C.3 onesim.physics.plasma.operators

The executable plasma operator examples appear in Sections 6.17.9–6.17.10.

from onesim.physics.plasma import operators

cell_transport_dae function

cell_transport_dae(base_operator)

Expose provider-owned cell transport and Poisson via common DAE methods.

Preserves chemistry and face laws. The selected provider must explicitly publish physical semidiscrete rates, algebraic balances and sparse derivatives; backward-Euler residuals are never guessed to be rates.

periodic_cell_poisson_dae_constraint function

periodic_cell_poisson_dae_constraint(shape, extents, *, charge_fields, **options)

Native periodic FV Gauss law with one explicit global mean gauge.

Charge fields are scalar SI number densities; mapping values are signed particle charges in coulombs. All cell balances remain in the coupled DAE. Nonneutral accepted states are rejected, never repaired by a background.

periodic_cell_transport_dae function

periodic_cell_transport_dae(base_operator, poisson_constraint)

Extend actual native periodic transport with its global Poisson gauge.

Retains provider chemistry/face laws and full sparse cross derivatives. A different native Poisson source is rejected, not silently replaced by the declared charge inventory. Initial snapshots name the global DOF.

periodic_cell_transport_request function

periodic_cell_transport_request(shape, extents, *, initial_fields, potential_field_index, permittivity, coefficients, volume_rates, **options)

Prepare native closed-periodic FV geometry without artificial walls.

The caller supplies physical coefficients and volume laws. The resulting cell-only Poisson block is singular; solving requires an explicit global gauge through the common DAE, not the legacy cell-only time solve.

plasma_condition_binding function

plasma_condition_binding(provider: object, problem_template: object, **options: object) -> object

Create the backend-owned IR-to-plasma condition adapter.

plasma_operator function

plasma_operator(provider: object, problem: object, *, final_time: float | None = None, field_ids: Sequence[str] = (), field_units: Sequence[str] = ()) -> object

Expose an explicit multispecies plasma provider through Study.

The provider owns chemistry and face-resolved plasma boundary semantics; the common runner owns time integration and result lifecycle. Requiring the provider and its typed problem as arguments keeps that boundary explicit and prevents a generic numerical factory from guessing a plasma state or mesh interpretation.
