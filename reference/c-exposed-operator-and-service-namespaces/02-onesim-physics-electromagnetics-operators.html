C.2 onesim.physics.electromagnetics.operators

The executable electromagnetic operator examples appear in Sections 6.7.6–6.7.8.

from onesim.physics.electromagnetics import operators

maxwell_dae_heating function

maxwell_dae_heating(base_operator, constraint, *, energy_field, energy_unit=None, power_field='absorbed_power_density', volumetric_heat_capacity=None, heat_capacity_unit='J/(m^3*K)')

Add native candidate-coupled Maxwell power to one complete DAE rate.

Infers physical energy-density units from provider result metadata, or accepts an explicit unit. Preserves all chemistry/transport/Poisson rows; energy conversion and sparse cross derivatives remain backend-owned.

maxwell_heated_equation function

maxwell_heated_equation(equation, *, energy_field, power_field='absorbed_power_density', electric_fields=('electric_real', 'electric_imaginary'), material_fields=(), volumetric_heat_capacity=None, heat_capacity_unit='J/(m^3*K)', provider_owned_mass=False)

Declare conservative native Maxwell work in one energy equation.

Retains the original chemistry/transport/external heating terms. Native work is an additional source in the energy state's declared units; W/m^3 power is derived, not another time-evolved degree of freedom. Runtime acknowledgement still requires an actual provider-owned source. This helper alone does not supply a coupled Study factory.

nedelec_maxwell_dae_constraint function

nedelec_maxwell_dae_constraint(*, coordinates, cells, carrier_id, source, curl_coefficient=1.0, mass_coefficient=1.0, essential_edge_ids=None, essential_edge_values=None, boundaries=(), material=None, material_fields=None, material_state=None, material_coefficient_scale=1.0, electric_real_field='electric_edge_real', electric_imaginary_field='electric_edge_imaginary', field_id='electric_field', service=None, configuration=None, element_order=1, quadrature_order=None)

Native Tet4/Hex8 Maxwell constraints with complete H(curl) moments.

The common DAE solver owns the full material/edge candidate. This factory assembles but never invokes an inner Maxwell solve. Material coefficients and forcing are explicitly supplied weak-form data, not inferred units.

nedelec_maxwell_dae_equations function

nedelec_maxwell_dae_equations(*, domain='', material_fields=(), electric_real_field='electric_edge_real', electric_imaginary_field='electric_edge_imaginary', surface_terms=False, essential_traces=False, material_input_fields=())

Declare executable Tet4 edge-integral Maxwell/PEC residuals.

Electric unknowns are oriented integrals in V; physical weak rows are V/m. This does not select the base transport method or infer material data.

periodic_maxwell_dae_constraint function

periodic_maxwell_dae_constraint(operator, *, material_fields, electric_real_field='electric_real', electric_imaginary_field='electric_imaginary')

Build backend-owned Maxwell constraint/codec derivatives for a DAE.

A dependency selects a scalar field by its ID, or a vector component by {"field_id": "B", "component": 0}. Multiple dependencies may select the same field/component; their analytic partials are added in the actual semantic codec. Component indices are zero-based, never inferred.

periodic_maxwell_dae_equations function

periodic_maxwell_dae_equations(*, domain='', material_fields=(), electric_real_field='electric_real', electric_imaginary_field='electric_imaginary')

Declare the two integrated native-edge Maxwell constraints.

Material fields name the actual cell-state dependencies (declared by their own equations). This describes the native periodic FV dialect; it does not select a provider or pretend to supply a coupled Study factory. The electric fields are algebraic real tangential edge values.

periodic_maxwell_dae_heating function

periodic_maxwell_dae_heating(base_operator, constraint, **settings)

Compatibility name for the common native Maxwell energy composition.

periodic_maxwell_energy_rate function

periodic_maxwell_energy_rate(base_operator, constraint, *, energy_field, power_field='absorbed_power_density', energy_unit=None, volumetric_heat_capacity=None, heat_capacity_unit='J/(m^3*K)')

Add native Maxwell absorption to an owned cell energy/temperature rate.

The common DAE adapter owns full implicit stages and codec ordering. The base operator owns transport/chemistry/cooling; this adapter never launches a separate Maxwell solve. Uniform periodic FV, physical-real cell rate only. Temperature requires explicit fixed volumetric heat capacity and its unit; energy-density states use their owned unit scale without another capacity.

periodic_maxwell_fvm_operator function

periodic_maxwell_fvm_operator(*, shape, extents, wave_number_squared, relative_permittivity, source, field_id='electric_field', material_state=None)

Prepare uniform periodic mimetic FVM Maxwell for StationaryStudy.

Extents are in metres; source is edge-sampled curl-curl forcing (V/m^3). Permittivity is a scalar or constant complex 3x3 Cartesian tensor. Native edge-diagonal arrays and MaterialPropertyEvaluator spatial scalar or tensor expressions are supported. The backend samples x/y/z at native edges or shared staggered edge-pair midpoints respectively. Explicit material_state binds real scalar parameters or native cell-centre fields for tensor IR. material_jvp includes their physical transfer. This does not substitute for STEP/PEC or a fully coupled ECR runtime.

periodic_maxwell_material_coupling(coupling_id, *, target, source, operator, dependency)

periodic_maxwell_power_coupling function

periodic_maxwell_power_coupling(coupling_id, *, target, source, operator, dependency, residual_measure)

Return native Maxwell absorption to an energy balance in common Newton.

Pair with periodic_maxwell_material_coupling in the opposite direction. The target cell balance must explicitly choose density (W/m^3) or cell_integral (W) residuals. No prescribed-power normalization is applied. Native peak phasors use exp(-i omega t). Tensor deposition may be signed locally; clipping is deliberately forbidden. This is periodic FV only.
