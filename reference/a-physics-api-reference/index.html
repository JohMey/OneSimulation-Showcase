A Physics API reference

Each section gives the import package. For example, use from onesim.physics.heat_transfer import HeatConduction. The signatures show exposed arguments and defaults. Angle brackets identify a default supplied by a factory or a callable object. Type names are shortened for readability. A declared field is accessed through an explicit model property or model.field(name). Some fields are created per species or component and are available through instance methods. Inspect model.fields() on the configured model. All sixteen domain package exports are included.
