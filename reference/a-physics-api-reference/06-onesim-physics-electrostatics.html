A.6 onesim.physics.electrostatics

FixedPotential class

FixedPotential(*, boundary: object, physics: object, value: object) -> None

Apply an electrostatic potential trace in volts to the named boundary.

NormalElectricDisplacement class

NormalElectricDisplacement(*, boundary: object, physics: object, value: object) -> None

Prescribed outward D dot n, positive charge flux in C/m^2.

Selected methods.

electric_displacement(*, points, time)

PoissonEquation class

PoissonEquation(*, domain, permittivity, charge_density=None, charge_density_source=None, model_id=None)

Solve electrostatic potential from charge and permittivity, and evaluate electric field from the negative potential gradient.

Declared fields. potential (V, algebraic), electric_field (V/m, derived, x/y/z), charge_density (C/m^3, input).

ZeroNormalElectricDisplacement class

ZeroNormalElectricDisplacement(*, boundary: object, physics: object) -> None

Prescribe zero outward normal displacement on a Poisson boundary.

Selected methods.

electric_displacement(*, points, time)
