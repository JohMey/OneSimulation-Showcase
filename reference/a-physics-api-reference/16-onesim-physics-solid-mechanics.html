A.16 onesim.physics.solid_mechanics

BilinearCohesiveLaw class

BilinearCohesiveLaw(*, peak_traction: float, onset_opening: float, final_opening: float) -> None

Evaluate a bilinear irreversible traction-separation law.

Selected methods.

traction_derivative(opening)

Selected branch tangent for monotonic opening without prior damage.

damage_derivative(opening)
evaluate(opening: float, previous_damage: float = 0.0) -> CohesiveZoneResult

BodyForce class

BodyForce(*, value: object) -> None

Supply a Cartesian force per volume to the elastic model.

CohesiveOpening class

CohesiveOpening(*, domain: object, model_id: str = <factory>, opening_rate: float | None, cohesive_law: object) -> None

Advance opening and damage with a selected traction–separation law.

Declared fields. opening (m, differential), work_per_area (J/m^2, differential), traction (Pa, derived), damage (1, derived), imposed_rate (m/s, input).

FatigueCrackGrowth class

FatigueCrackGrowth(*, domain: object, model_id: str = <factory>, stress_range: float | None, frequency: float | None, growth_law: object, geometry_factor: float = 1.0) -> None

Advance a crack-length state using the selected cyclic growth law and load range.

Declared fields. crack_length (m, differential), loading_range (Pa, input), cycling_rate (1/s, input). Selected methods.

rate(crack_length, *, stress_range=None, frequency=None)

FixedDisplacement class

FixedDisplacement(*, boundary: object, physics: object, value: object) -> None

Prescribe Cartesian displacement on a selected elastic boundary.

HertzContactLaw class

HertzContactLaw(effective_modulus: float, effective_radius: float) -> None

Compute elastic contact response from effective modulus and radius.

Selected methods.

force(indentation)
stored_energy(indentation)
force_derivative(indentation)
stored_energy_derivative(indentation)

HertzImpact class

HertzImpact(*, domain: object, model_id: str = <factory>, reduced_mass: float, contact_law: object, force: float | None = 0.0) -> None

Advance normal contact motion using a Hertz contact law and reduced mass.

Declared fields. indentation (m, differential), approach_velocity (m/s, differential), contact_force (N, derived), mechanical_energy (J, derived), load (N, input).

IsotropicThermalExpansion class

IsotropicThermalExpansion(*, reference_temperature: float) -> None

Set the stress-free reference temperature for isotropic thermal strain.

Selected methods.

evaluate(*, temperature, coefficient)
evaluate_array(*, temperature, coefficient)

The same physical expansion law on explicitly supplied point states.

LinearElasticity class

LinearElasticity(*, domain: object, model_id: str = <factory>, material: object, thermal_strain: IsotropicThermalExpansion | None = None, loading: object | None = None) -> None

Solve displacement and stress from an elastic material, loads and optional thermal strain.

Declared fields. displacement (m, algebraic, x/y/z), temperature (K, input), body_force (N/m^3, input, x/y/z), stress (Pa, derived, xx/yy/zz/xy/yz/xz), von_mises_stress (Pa, derived), thermal_strain_tensor (1, derived, xx/yy/zz/xy/yz/xz).

MaxwellRelaxation class

MaxwellRelaxation(*, domain: object, model_id: str = <factory>, youngs_modulus: float, viscosity: float, strain_rate: float | None = 0.0) -> None

Advance the viscoelastic stress of a Maxwell element driven by strain rate.

Declared fields. stress (Pa, differential), imposed_strain_rate (1/s, input).

ParisLaw class

ParisLaw(coefficient: float, exponent: float) -> None

da/dN=C*DeltaK**m, with SI DeltaK in Pa*sqrt(m), a in m, N cycles.

Selected methods.

advance_per_cycle(stress_intensity_range)
rate_derivative(stress_intensity_range)

StructuralOscillator class

StructuralOscillator(*, domain: object, model_id: str = <factory>, mass: float, stiffness: float, damping: float = 0.0, force: float | None = 0.0) -> None

Advance displacement and velocity for a single mass, spring and damper.

Declared fields. displacement (m, differential), velocity (m/s, differential), mechanical_energy (J, derived), load (N, input).

Traction class

Traction(*, boundary: object, physics: object, value: object) -> None

Prescribed Cartesian surface force sigma*n, in Pa, on a physical face.

Selected methods.

traction(*, points, time)

TractionFree class

TractionFree(*, boundary: object, physics: object) -> None

Set zero surface traction on a selected elastic boundary.

Selected methods.

traction(*, points, time)
