Quickstart

Install OneSimulation Runtime Alpha 0.2.1a8 and run the STEP example.

1. What you need

Use standard 64-bit CPython 3.13 on macOS (Apple Silicon), Ubuntu 22.04 (x86-64), and Windows x64 with the GIL enabled. You also need internet access to install dependencies and activate the runtime.

Choose the ZIP for your system. On Ubuntu and Windows, follow its README.md for installation, activation and the STEP example. These builds use the portable numerical backends.

Check that the interpreter reports Python 3.13 and your platform architecture. On macOS, expect arm64. On Ubuntu, expect x86_64. On Windows, expect AMD64.

On macOS and Ubuntu:

python3.13 -c 'import platform, sys; print(sys.version); print(platform.machine())'

On Windows:

py -3.13 -c "import platform, sys; print(sys.version); print(platform.machine())"

2. Get the runtime

  1. Open the Gumroad email for OneSimulation Multiphysics Alpha – Python Runtime and click View content.
  2. Choose the ZIP for your system. On macOS, click OneSimulation-Runtime-0.2.1a8-macOS-AppleSilicon.zip. It contains onesimulation-0.2.1a8-cp313-cp313-macosx_11_0_arm64.whl and README.md.
  3. Find License key on the Gumroad page or in the receipt. Keep the receipt open so you can copy the key during activation.

Compare plans and open Gumroad.

3. Install

On macOS, unpack the ZIP and run these commands in the extracted directory. The installation, activation and first-run commands below use the macOS shell.

python3.13 -m venv .venv-onesimulation
.venv-onesimulation/bin/python -m pip install './onesimulation-0.2.1a8-cp313-cp313-macosx_11_0_arm64.whl[meshing,compute,visualization]'
.venv-onesimulation/bin/python -m pip check

4. Activate

Activation binds the licence to this device and your local user account. With an internet connection, run the first command and paste the Gumroad key when Terminal asks for it. The pasted characters stay hidden. Press Enter, then run the second command to check activation.

.venv-onesimulation/bin/onesimulation-license activate-gumroad
.venv-onesimulation/bin/onesimulation-license status

After a successful activation, status reports "valid": true and "runtime_access": true. The activation renews itself online while your subscription is active.

5. Run the STEP example

Open the STEP example and download step-import.py into the extracted folder. Run it with the activated environment.

.venv-onesimulation/bin/python step-import.py

The script creates a STEP file for the sample sleeve, reads it back, solves the load case and writes its checks and ParaView exports to ergebnisse_onesimulation/.

6. Build and run studies through MCP

Install the optional MCP integration in the same environment. Then register the included local server from the extracted folder. Replace the workspace path with the folder that holds your OneSimulation projects.

.venv-onesimulation/bin/python -m pip install './onesimulation-0.2.1a8-cp313-cp313-macosx_11_0_arm64.whl[agent]'
codex mcp add onesimulation-runtime \
  --env 'ONESIMULATION_WORKSPACE=/absolute/path/to/workspace' \
  -- "$PWD/.venv-onesimulation/bin/onesimulation-mcp"

For Claude Code, register the same workspace from the directory where you will start Claude Code.

claude mcp add onesimulation-runtime --scope local --transport stdio \
  --env 'ONESIMULATION_WORKSPACE=/absolute/path/to/workspace' \
  -- "$PWD/.venv-onesimulation/bin/onesimulation-mcp"

Start a new session. For a new study, describe the dimensions, mesh settings, material and boundary conditions. The authoring tools support steady heat conduction in rectangular plates and boxes and linear elasticity in 3D boxes. Ask the client to save the study, start it and retrieve a result field. You can also start a saved study in the workspace. On Windows, keep the client connected until the solver completes. Keep the run ID to retrieve the fields and local HDF5 file.

If something goes wrong

  • The wheel is "not a supported wheel on this platform". The interpreter is not CPython 3.13 or does not match the wheel's platform. Renaming the file does not help.
  • A license error before the import. Run onesimulation-license status with the same user account you activated with.
  • "Already bound to a different device". A license covers one device and one local user account. For a device move, run onesimulation-license release-device on the old device and activate on the new one.

For help with installation or activation, reply to your Gumroad receipt.
