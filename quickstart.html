Quickstart

From download to a first 3D result in about ten minutes.

1. What you need

  • Python 3.13, the standard 64-bit CPython build. The free-threaded variant 3.13t and debug builds are not supported.
  • One of these platforms:
PlatformWheel
macOS, Apple Silicononesimulation-0.2.1a2-cp313-cp313-macosx_11_0_arm64.whl
Linux, x86_64onesimulation-0.2.1a2-cp313-cp313-linux_x86_64.whl
Windows, AMD64onesimulation-0.2.1a2-cp313-cp313-win_amd64.whl

Check your interpreter before you install:

python3.13 -c 'import platform, sys; print(sys.version); print(platform.machine())'

2. Get the runtime

As a student or course instructor, you have free access. Everyone else starts with the 7-day free trial on Gumroad. You receive a ZIP with the three wheels and your license key. Ready-to-run example notebooks are free in the Showcase.

3. Install

Create a fresh environment and install the wheel for your platform with its extras.

macOS

python3.13 -m venv .venv-onesimulation
.venv-onesimulation/bin/python -m pip install './onesimulation-0.2.1a2-cp313-cp313-macosx_11_0_arm64.whl[meshing,compute,visualization]'

Linux

python3.13 -m venv .venv-onesimulation
.venv-onesimulation/bin/python -m pip install './onesimulation-0.2.1a2-cp313-cp313-linux_x86_64.whl[meshing,compute,visualization]'

Windows (PowerShell)

py -3.13 -m venv .venv-onesimulation
.\.venv-onesimulation\Scripts\python.exe -m pip install '.\onesimulation-0.2.1a2-cp313-cp313-win_amd64.whl[meshing,compute,visualization]'

4. Activate

Activation binds the license to this device and your local user account. It needs an internet connection and asks for the key from your Gumroad receipt.

.venv-onesimulation/bin/onesimulation-license activate-gumroad
.venv-onesimulation/bin/onesimulation-license status

On Windows the command is .\.venv-onesimulation\Scripts\onesimulation-license.exe. After a successful activation, status reports "valid": true and "runtime_access": true. The activation renews itself online at regular intervals while your subscription is active.

5. Run a first model

Save this as cantilever.py and run it with the environment's Python, or paste it into a notebook cell.

from onesim.cad.d3 import Box
from onesim.materials import IsotropicSolid
from onesim.meshing import StructuredHexahedralMesher
from onesim.numerics import Numerics
from onesim.numerics.fem import FiniteElement, Lagrange
from onesim.numerics.linear import SparseDirect
from onesim.physics.solid_mechanics import (
    FixedDisplacement, LinearElasticity, Traction, TractionFree)
from onesim.simulation import Problem, Simulation

beam = Box(length=0.12, width=0.018, height=0.012)  # metres
aluminium = IsotropicSolid(
    density=2700.0, specific_heat_capacity=900.0, thermal_conductivity=200.0,
    youngs_modulus=70e9, poisson_ratio=0.30, thermal_expansion_coefficient=23e-6)
solid = LinearElasticity(domain=beam.volume, material=aluminium)
walls = beam.boundaries

problem = Problem(
    name="Cantilever", geometry=beam, physics=(solid,),
    boundary_conditions=(
        FixedDisplacement(boundary=walls.x_min, physics=solid, value=(0.0, 0.0, 0.0)),
        Traction(boundary=walls.x_max, physics=solid, value=(0.0, 0.0, -30.0 / (0.018 * 0.012))),
        TractionFree(boundary=walls.all - walls.x_min - walls.x_max, physics=solid),
    ))

result = Simulation(
    problem=problem,
    mesh=StructuredHexahedralMesher(cells=(16, 3, 3)).generate(beam),
    numerics=Numerics(spatial=FiniteElement(element=Lagrange(order=2)),
                      linear_solver=SparseDirect()),
).solve_stationary()

tip = result.field(solid.displacement).evaluate([[0.12, 0.009, 0.006]])
print(f"Tip deflection: {abs(tip[0, 2]) * 1e3:.4f} mm")  # 0.0948 mm

To work in notebooks, add JupyterLab and Matplotlib to the same environment:

.venv-onesimulation/bin/python -m pip install jupyterlab matplotlib
.venv-onesimulation/bin/python -m jupyterlab

If something goes wrong

  • The wheel is "not a supported wheel on this platform". The interpreter is not CPython 3.13 or does not match the wheel's platform. Renaming the file does not help.
  • A license error before the import. Run onesimulation-license status with the same user account you activated with.
  • "Already bound to a different device". Free the seat on the old device with onesimulation-license release-device, then activate again.
