Multiphysics simulation · in Python

A whole simulation lab in one Python package.

CAD, meshing, 16 physics modules, FEM, FVM, FDM and DG, implicit and explicit solvers, multiphysics coupling, plotting and storage behind one API. This is the documentation: how to install it, how to build a model, and what every module computes.

One model, five discretizations

The physics is declared once; the numerical method is an argument. The same 3D Poisson problem is solved with finite elements, finite volumes and finite differences on one mesh.

problem = Problem(name="Charge in a grounded box", geometry=cube,
                  physics=(field,), boundary_conditions=(grounded,))
mesh = StructuredHexahedralMesher(cells=(16, 16, 16)).generate(cube)

for spatial in (
    FiniteElement(element=Lagrange(order=1)),
    FiniteElement(element=Lagrange(order=2)),
    FiniteVolume(gradient=LeastSquaresGradient(),
                 diffusion=CentralDifference()),
    FiniteDifference(gradient=CentralDifference(),
                     diffusion=CentralLaplacian()),
    FiniteDifference(gradient=PolynomialDifference(accuracy_order=4),
                     diffusion=PolynomialLaplacian(accuracy_order=4)),
):
    result = Simulation(
        problem=problem, mesh=mesh,
        numerics=Numerics(spatial=spatial, linear_solver=SparseDirect()),
    ).solve_stationary()

What is inside

CAD built in

Parametric lines, rectangles, circles, boxes and cylinders with named boundaries. No external CAD program.

Meshing built in

Structured and tetrahedral meshes, linear and quadratic, with local refinement, periodic pairs and moving meshes.

16 physics modules

Flows, heat, solids, electromagnetics, plasma, MHD, chemistry, acoustics, optics, geotechnics, biophysics, multibody, networks.

FEM, FVM, FDM, DG

80 building blocks: Lagrange, Nédélec and Taylor–Hood elements, WENO, MUSCL, limiters, Scharfetter–Gummel, SBP operators.

Implicit and explicit

Runge–Kutta 4, forward and backward Euler, BDF, adaptive step control and events. Stationary solves too.

Direct, Krylov, Newton

Sparse direct, CG, GMRES, ILU, algebraic multigrid, block and Schur preconditioners, Newton variants, JFNK.

Real multiphysics

Monolithic, partitioned and sequential coupling. Pass any solved field into any other model, across meshes.

Your own equations

Declare a PDE by its coefficients, or write a physics model of your own. It runs through the same numerics.

Analysis built in

Probes, line and plane sections, volume and flux integrals, conservation checks and mesh-convergence studies.

Plots and animations

Line plots, slices, time series, animations and an interactive result explorer, straight from the result object.

Save, version, resume

HDF5 output, result versions, portable archives and checkpoints that restart long transient runs.

Compiled where it counts

Numba-compiled kernels and sparse solvers on all CPU cores. Cluster interfaces for SLURM, MPI and PETSc are in the package; they are not yet qualified in this Alpha.

Status

OneSimulation is an alpha. The depth of the modules differs: some solve full 3D field problems, others provide reduced or one-dimensional models. Each example page states the model, its resolution and its limits. The results are numerically verified against references; they are not experimentally validated.
