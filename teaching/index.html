For instructors

Teach numerical methods with one toolkit.

OneSimulation is free for a course. Students declare a model once and change the method, the solver or the mesh in one line, so a lab can compare methods instead of rewriting code.

Apply for course access →The 14-week lab course →Exercise sheets →

Why it fits a course

One model, many methods

Finite elements, finite volumes, finite differences and DG on the same problem. Order, cost and limits become measurable in one session.

Verification built in

Every worked example compares with an exact solution, a balance or a refinement study. Students learn to check before they plot.

Breadth without new tools

Heat, solids, flow, electromagnetics and more use the same objects, so a project in week 13 needs no new software.

What you get

  • One course code with a seat for every participant, free of charge, valid for the course and at most twelve months.
  • The complete runtime with all 16 physics modules and every numerical method. Nothing is removed for teaching.
  • A 14-week lab course and eight exercise sheets on this site, each tied to a worked section of the guide.
  • The guide and the API reference online, and both books as free PDFs.

What your students need

  • Their own computer with macOS on Apple Silicon, Linux on x86_64 or Windows on AMD64.
  • Python 3.13 and basic Python. The Quickstart has the commands.
  • An internet connection for activation and its regular renewal.

What to know before you plan

  • OneSimulation is an alpha. The depth of the modules differs; the course uses the parts with worked and checked examples.
  • A licence covers one person and one device. Shared computer pools are not supported yet.
  • The free example notebooks are in German. This site and the guide cover the same workflows in English.
  • Course access is for teaching and coursework. Research projects and paid work need a paid plan.

How to apply

Apply with your university email address and name the course, its web page and the number of participants. Each application is checked by hand. You receive one code and pass its link to your students; each of them redeems it once.
