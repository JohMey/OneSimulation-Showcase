5 Build a first case in each physics package

The following sections use the canonical import path shown under each heading. Paths beginning with test_ refer to implementation/tests/api_target/ in the source checkout. They give specific model and method combinations with verification criteria. The configuration, provider, state and result types in several packages also support a domain service route. Start from the model declaration when it provides the field-based workflow used in this guide. For the service route, construct the matching configuration and use the facade's validation and execution methods. Pass state and result objects through the corresponding provider and adapter family. Appendix A identifies those types and their arguments.
