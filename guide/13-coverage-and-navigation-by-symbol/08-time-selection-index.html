13.8 time selection index

See Section 9.7 for a worked comparison in this layer.

TimeEventDefinition. Provide an event function of accepted semantic state, a direction and terminal behavior. For a field-based terminal event the time lab uses FieldThreshold. Example in Section 10.1.3.

TimeMethod. Select a registered time algorithm by method_id, then supply the stage solver required by its binding. Example in Section 9.7.1.

ClassicalRungeKutta4. Select the four-stage explicit fourth-order RK method. The time step must resolve the spatial stability bound. Example in Section 9.9.1.

ForwardEuler. Select first-order explicit Euler with separately declared step limits. Example in Section 9.7.1.

BackwardEuler. Select first-order implicit Euler and supply a compatible nonlinear stage solver when required. Example in Section 9.7.1.

BDF. Select backward differentiation order, startup policy and maximum step ratio. Keep its history for continuation. Example in Section 9.7.2.

AdaptiveTimeStep. Pass as run(time_step=...) to choose the trial step range, error tolerances, safety and rejection limits. Example in Section 9.7.2.

TimeStepLimits. Pass through Numerics.step_limits to bound the maximum step, stability safety factor and optional CFL. Example in Section 10.1.3.

TimeExecutionBinding. Read the bound method, nominal order, stage configuration, startup policy and stage-projection capabilities. Example in Section 10.1.3.
