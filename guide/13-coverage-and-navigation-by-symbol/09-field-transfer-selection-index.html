13.9 field_transfer selection index

See Section 9.8 for a worked comparison in this layer.

GlobalBroadcastTransfer. Send an owned global scalar or vector to a compatible spatial input as a uniform value. Example in Section 10.2.19.

SpatialAverageTransfer. Integrate a native spatial field and divide by its physical measure using the selected quadrature. Example in Section 10.2.19.

GlobalValueTransfer. Send a global value to another compatible global input without a spatial sampling step. Example in Section 9.9.1.

FiniteElementEvaluation. Evaluate an FE field on the receiver's requested physical points, such as mechanical quadrature. Example in Section 5.13.1.

CellToQuadratureProjection. Map native cell data to the receiving quadrature support through the bound evaluator. Example in Section 10.2.19.

FieldInterpolation. Interpolate a field to a compatible receiving support using the selected transfer factory. Example in Section 10.2.19.

ElectricFieldToFaces. Provide the electric field on target faces, with an explicit periodic potential trace when needed. Example in Section 10.2.20.

PeriodicPotentialTrace. Set the signed potential increase from the first periodic face to the second. Example in Section 10.2.20.

ConservativeVolumeTransfer. Integrate an FE scalar density over physical FV overlaps. Configure coverage and quadrature tolerances for the receiving cells. Example in Section 10.2.21.
