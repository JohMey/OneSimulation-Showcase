13.5 fem selection index

See Section 9.4 for a worked comparison in this layer.

HcurlNitsche. Use in boundary_enforcement for weak tangential traces with a dimensionless penalty. Example in Section 10.2.16.

ConstraintAugmentation. Add a weighted constraint contribution to a compatible primal block while preserving the exact constraint. Example in Section 10.2.16.

FiniteElement. Choose an element space, integration rule, stabilization, boundary enforcement and compatible term components. Example in Section 9.5.1.

Lagrange. Use as element for a continuous nodal space. Order is total degree on simplices and per-coordinate degree on supported hexahedra. Example in Section 9.5.1.

DiscontinuousLagrange. Use as element for cell-local polynomials. Order zero gives a cellwise constant space. Example in Section 9.4.2.

Nedelec. Use as element for first-family H(curl) edge elements. The positive public order starts at one. Example in Section 6.17.7.

ConsistentMassStability. Compute a compatible generalized spectral bound from the free stiffness and consistent mass blocks. Configure dense threshold and eigensolver tolerance. Example in Section 10.2.10.

SUPG. Select streamline-upwind Petrov–Galerkin stabilization with tau and a supported strong residual. Example in Section 10.2.8.

GLS. Select Galerkin least-squares stabilization with a scale tau and a compatible strong residual. Example in Section 10.2.8.

CIP. Select a continuous interior penalty on jumps of physical first derivatives. Example in Section 10.2.8.

DGPolynomialLimiter. Apply a slope reduction and optional convex admissibility scaling on a compatible DG stage. Example in Section 10.2.9.

StateLimiterPort. Implement the limiter contract consumed by a bound conservative stage. Apply the change on the stage carrier and check admissibility and preserved means. Example in Section 10.2.9.

ScalarInterval. Constrain the named scalar field to an interval by mean-preserving scaling in a supported limiter. Example in Section 10.2.9.

DGJumpPenalty. Use a jump-based interior dissipation contribution with an explicit nonnegative coefficient. Example in Section 10.2.8.

SymmetricInteriorPenalty. Select symmetric interior-penalty diffusion for DG with an explicit penalty. Example in Section 10.2.8.

InvariantDomainGraphViscosity. Choose a continuous-graph viscosity treatment using a selected mass operator and invariant domain. Example in Section 10.2.24.

RowSumLumping. Supply row-sum mass lumping to a compatible nodal or graph-viscosity method. Example in Section 10.2.4.

OrderedFields. Pass the lower and upper field names and minimum separation as an invariant domain for a compatible limiter. The waterbag recipes illustrate the required ordering. Example in Section 10.2.9.

TaylorHood. Select a mixed velocity–pressure space with pressure one polynomial degree lower than velocity. Example in Section 6.11.7.

GradDiv. Select a penalty on the divergence of the velocity in a compatible mixed momentum assembly. Example in Section 10.2.12.

MixedMomentumContribution. Provide explicit mass, momentum, pressure or load pieces for the mixed momentum assembly. Example in Section 10.2.12.

Nitsche. Enforce compatible diffusion or inflow traces weakly. Penalty and symmetry select the boundary form. Example in Section 6.9.3.

RaviartThomas. Use as the H(div) flux space with polynomial subdegree k. RT0 has order zero. Example in Section 9.4.2.

MixedDiffusionElement. Pair an H(div) flux space with a discontinuous scalar element for a mixed diffusion solve. Example in Section 9.4.2.

BrezziDouglasMarini. Use as the H(div) flux space with complete vector polynomials of order at least one. Example in Section 9.4.2.

GalerkinDiffusion. Select the Galerkin diffusion contribution where the physical residual exposes that port. Example in Section 6.11.8.

VolumeCIP. Supply an explicit diffusivity for continuous interior-penalty contributions on supported volume FE interior facets. Example in Section 10.2.11.

InterpolatedFluxDivergence. Select this convection contribution for a continuous formulation that interpolates the physical flux before taking its divergence. Example in Section 10.2.11.

PSPG. Set the stabilization time scale for the supported pressure-stabilized mixed residual. Example in Section 10.2.12.

MixedContinuityContribution. Provide explicit mass, velocity, pressure or load pieces for the mixed continuity assembly. Example in Section 10.2.12.

EqualOrderVelocityPressure. Select equal-degree velocity and pressure spaces with a compatible stabilized formulation. Example in Section 10.2.12.

HydrostaticGraphViscosity. Combine graph viscosity with hydrostatic equilibrium and a shallow-water invariant domain. Example in Section 10.2.4.

GalerkinAdvection. Select the Galerkin advection contribution in an appropriate finite-element weak form. Example in Section 6.11.8.

DissipativeMassStability. Resolve a spectral interval or an M-norm contractivity bound for the supported dissipative operator. Example in Section 10.2.10.
