13.4 fvm selection index

See Section 9.3 for a worked comparison in this layer.

MonotoneUpwind. Select scalar upwinding with a physical flux monotone in the declared direction. Example in Section 10.2.3.

FiniteVolume. Compose control-volume term operators, reconstruction, limiter, initialization, and cell and face quadrature. Example in Section 10.2.3.

Rusanov. Select the local Lax–Friedrichs flux using the physical model's wave-speed estimate. Example in Section 10.2.4.

LinearUpwind. Select a linear upwind reconstruction for the compatible FV convective operator. Example in Section 3.2.

CentralDifference. Select the central FV diffusion contribution on supported carriers. This is a different declaration from fdm.CentralDifference. Example in Section 10.2.13.

LeastSquaresGradient. Choose least-squares reconstruction of cell gradients for supported face fluxes and field diagnostics. Example in Section 3.2.

RhieChow. Select collocated face-velocity interpolation with pressure correction in a supported flow model. Example in Section 10.2.13.

ScharfetterGummel. Choose an exponential-fitting flux for drift–diffusion. Supply a gradient collaborator if the binding requires one. Example in Section 6.17.6.

ImplicitLocalSources. Select the implicit local source treatment for models exposing a compatible reaction or source operator. Example in Section 6.17.6.

DifferentiableSamples. Create differentiable samples with DifferentiableSamples.variables(values) and propagate the sparse tangent through supported arithmetic. Inspect .jacobian alongside .values. Example in Section 9.3.2.

MimeticCurl. Choose the mimetic discrete curl route for supported electromagnetic models. Example in Section 10.2.25.

TwoPointDiffusion. Select a two-point diffusion flux based on adjacent cell values. Example in Section 7.5.

MUSCL. Reconstruct conservative piecewise-linear face states. Select the limiter separately. Example in Section 5.4.

ConvexInvariantDomain. Retract face states toward their unchanged cell mean to satisfy the bound invariant domain. Example in Section 10.2.7.

MinmodLimiter. Limit two scalar one-sided slopes with minmod to obtain a TVD slope on the supported stencil. Example in Section 9.3.1.

MonotonizedCentralLimiter. Use a monotonized central TVD slope with less flattening than minmod in smooth regions. Example in Section 10.2.5.

VanLeerLimiter. Use a harmonic TVD slope where the one-sided slopes agree in sign. Example in Section 9.3.1.

HydrostaticReconstruction. Reconstruct depth and discharge consistently with the bed for a supported well-balanced method. Example in Section 6.11.4.

WetDryActiveSet. Select the wet/dry active-set treatment for a compatible shallow-water linearization. Example in Section 10.2.22.

SuperbeeLimiter. Choose a compressive TVD limiter for a compatible scalar slope reconstruction. Example in Section 10.2.5.

VenkatakrishnanLimiter. Use smooth slope limiting with a regularizing epsilon. Example in Section 10.2.5.

BarthJespersenLimiter. Limit reconstructed values to the local neighbor range on a supported multidimensional stencil. Example in Section 10.2.5.

TvbLimiter. Wrap a base limiter with a mesh-width and curvature threshold for suppressing limiting near smooth extrema. Example in Section 10.2.5.

BoundaryLeastSquaresGradient. Reconstruct cell gradients with boundary data through the supported least-squares port. Example in Section 10.2.17.

CentralElasticStress. Choose the central FV stress contribution for a compatible elasticity formulation. Example in Section 10.2.17.

WetDryTraceScaling. Retract depth and discharge traces by one factor toward admissible means. Example in Section 10.2.7.

Eno2Reconstructor. Select a smooth second-order scalar ENO stencil at the face. Example in Section 10.2.6.

Eno3Reconstructor. Select a smooth quadratic scalar ENO stencil at the face. Example in Section 10.2.6.

Weno3Reconstructor. Reconstruct a scalar left trace with WENO3 weights on the supported uniform line stencil. Example in Section 10.2.6.

Weno5Reconstructor. Reconstruct a scalar left trace with WENO5 weights on the supported uniform line stencil. Example in Section 10.2.6.

CellGradientReconstruction. Declare a native cell-gradient reconstruction component for compatible volume carriers. Example in Section 10.2.23.

FiniteIntegration. Select a discrete incidence complex and metric Hodge maps for a compatible curl operator. Example in Section 10.2.26.

WhitneyHodge. Use Whitney reconstruction for metric edge and face maps, with optional reconstruction collaborators. Example in Section 10.2.26.

OrientedCellComplex. Represent oriented incidence between discrete geometric entities, independently of the metric. Example in Section 10.2.26.

OrthogonalHodge. Select orthogonal metric Hodge maps on a supported orthogonal carrier. Example in Section 10.2.26.
