13.6 linear selection index

See Section 9.5 for a worked comparison in this layer.

GMRES. Select restarted or unrestarted GMRES with tolerances, scalar type, and an optional compatible preconditioner. Example in Section 9.6.1.

RightGMRES. Use fixed right preconditioning and check convergence on the physical residual. Example in Section 9.5.1.

FlexibleGMRES. Use flexible right preconditioning, retaining the actual preconditioned search vectors. Example in Section 9.5.1.

ConjugateGradient. Solve a compatible positive-definite symmetric or Hermitian linear system. Check the operator and preconditioner guarantees. Example in Section 9.5.1.

SparseDirect. Select assembled sparse factorization for the declared scalar type and available provider. Example in Section 9.7.2.

ComplexSparseDirect. Select the complex sparse direct route, for example for frequency-domain Maxwell phasors. Example in Section 6.7.5.

ILU. Use incomplete sparse factorization with selectable fill and drop tolerance. Example in Section 9.5.1.

AlgebraicMultigrid. Use a compatible multigrid preconditioner with optional near-nullspace information. Example in Section 10.2.13.

BlockPreconditioner. Use a diagonal or triangular sweep of inner solvers over an explicit or provider-owned block partition. Example in Section 10.2.15.

SchurPreconditioner. Use a leading-block solve and Schur-complement solve, with an optional approximation. Example in Section 10.2.15.
